# Agent Instructions — CosmicLayer

- Read this file before making changes.
- Preserve the existing architecture and inspect files before editing.
- Use TypeScript strict mode; avoid `any`.
- Keep browser and desktop integrations separate.
- Never claim native desktop UI support without a documented API and a working test.
- Do not access prompts, conversations, cookies, credentials, or authentication tokens.
- Keep wallpaper assets and settings local by default.
- Use minimum required permissions.
- Every visible control must work.
- Run `npm run typecheck` and `npm run build` after implementation changes.
- Do not overwrite unrelated files or force-push branches.
