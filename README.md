# CosmicLayer — Universal AI Interface Customizer

A futuristic, local-first customization toolkit for supported AI workspaces.

**One Universe. Every AI Workspace. Your Style.**

## Foundation v0.1.0
The implementation branch is being initialized with a Chrome Manifest V3 + React + TypeScript foundation. Planned browser targets: ChatGPT, Claude and Gemini. Planned IDE integrations: supported Antigravity, Claude Code and Codex extension APIs.

A browser extension cannot modify native terminal or desktop application interfaces. Native integrations must use documented extension or theme APIs. Unsupported surfaces must not be represented as working.

## Privacy
Keep wallpaper data and preferences local. CosmicLayer does not need access to AI prompts, conversations, cookies, credentials or account tokens.
